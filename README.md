# OpenAI-Java-discord-bot
This is a java bot I followed a youtube tutorial with for the most part. I did make some changes myself and modified it to be unique. The .env file is unincluded for safety purposes as it contains both the token to my discord bot and the openai_key.

With the discord bot token you could essentially run any malicious code you wanted, as long as you had that token you could pose as my discord bot which could cause lots of problems.
The openAI_key is also not included as that has a limited number of tokens I purchased available, if it was public they could all be used up.
